# Теплица 0.15 га — ночной автопилот (v2)

## Концепция

Одна цель: маленький фермер с 0.15 га не жег лишний газ ночью и не продавал огурцы в убыток днем. Без найма агронома и теплотехника.

Два блока решений:
- **Ночь**: погода → тепловая модель → топливо → оптимизатор 3 профиля → EV-решение «топить/держать».
- **Неделя**: цены БНС + импорт Comtrade → МЛ Ridge → индекс риска просадки → совет «везти/держать».

LLM не считает деньги и не принимает решения. LLM — только уши (понимает слова фермера), рот (объясняет решение словами) и сторожилка (подсвечивает аномалии газа). Цифры считает только код.

## Формулы и МЛ-модели

### Теплофизика (physics.py, dynamics.py)
Статика ночи: `Q = U*A*dT + 0.33*N*V*dT` [Вт]
- `U` — коэффициент теплопередачи (пленка 6.2, поликарбонат 3.7, стекло 5.8)
- `A` — площадь ограждения (стены + крыша с K_ROOF=1.2)
- `N` — кратность воздухообмена (база 0.75, + ветер >4 м/с)
- `V` — объем теплицы

Динамика 2 узла (ночь, без солнца):
- `C_air*dT_in/dt = Q_heat - G*(T_in-T_out) + hA*(T_soil-T_in)`
- `C_soil*dT_soil/dt = -hA*(T_soil-T_in) - k_deep*(T_soil-T_deep)`
Почва — теплоаккумулятор 125 кВт*ч/К на 0.15 га. Без неё модель завышает газ в 2 раза.

### Топливо (fuels.py)
Цена за кВт*ч тепла:
- газ: `тариф / (LHV 9.3 * КПД 0.90 * fouling)`
- уголь хороший: LHV 6.1, КПД 0.65; уголь пыль/песок (Шымкент-2023): LHV 3.9, КПД 0.45
- `fouling 1.0` чистый → `0.65` забитый

### Оптимизатор (optimizer.py)
3 профиля: P1 flat, P2 econight, P3 screen (U*0.6).
`J = cost + EV -> min`. Экран платный: амортизация + работа за Nacht (4000 тг дефолт, 500 если уже куплен).

### Решение (decision.py)
Маржинальный EV вместо порога 0.5:
- `heat если (p_noheat - p_freeze) * Loss_max > Cost` — сравнение с ночью без отопления
- тёплая ночь: `p_noheat ≈ p_freeze` → «держать»; холодная: `p_noheat >> p_freeze` → «топить»
- `p* = Cost / Loss_max` (0.002-0.004, не 0.5)
- `loss_tg` — уже матожидание, не умножать на p дважды
- `decide_price()` — недельное решение sell_early/hold (экран «Неделя» не может ответить «топить»)

### Риск заморозка (freeze.py)
Логистика: `p = 1/(1+exp(-(A*HDD + B)))`, A=0.045, B=-2.7
- HDD = сумма max(0, Tcrit - T_in) по часам
- p(10)=0.10, p(60)=0.50, p(112)=0.91
Требует полевой калибровки на 7+ ночах.

### Цена и импорт (price_risk.py)
`RidgeCV + TimeSeriesSplit` на лагах t-1 и старше:
`sin/cos недели, price_lag1/2, import_lag2/3, spread=taraz-mean, kzt_rub_lag1, tashkent_T_avg3w, holiday`
- `p_dump` — индекс риска просадки 0-1, НЕ вероятность (калибровка Platt)
- БНС через `load_bns_xlsx()` (лист 5, город по слову)
- Comtrade импорт: reporterCode=398, cmdCode=0702/0707, flowCode=M

### LLM (ai_assistant.py, llm_verbalizer.py)
- **Уши**: текст фермера -> параметры (fuel, coal_quality, fouling, crop, readiness). LLM JSON + keyword-фолбэк.
- **Рот**: объяснение решения, проверка чисел регуляркой, откат на шаблон.
- **Сторожилка**: отклонение газа от модели >30% -> флаг "забитый котел/пленка".
- **Конклюжн по импорту**: p_dump + спред + импорт -> совет собрать раньше / держать.

### Данные
Погода (бесплатно): api.open-meteo.com/v1/forecast, archive-api (ERA5), ensemble-api (икон/ГФС/ECMWF).
Цены (руками, Excel): stat.gov.kz/ru/industries/economy/prices/spreadsheets/ (еженедельный недельник с 2022).
Импорт (с ключом): comtradeapi.un.org.
Свои данные с фермы: 7 ночей t_in/t_out/газ/ветер для (U,N); 5 ночей датчика почвы для hA.

## Свои данные с фермы

Минимум чтобы модель стала своей, а не «средней теплицы»:
- **Тепла**: 7 ночей записи `t_in, t_out, газ м3, часы, ветер` -> калибровка `(U, N)` через `calibrate_UN`
- **Почва**: 5 ночей датчика на 10 см -> калибровка `hA` через `calibrate_soil`
- **Деньги**: урожайность кг/м2 и цена сдачи тг/кг -> без них EV считает с допущениями (10 кг * 300 тг)
